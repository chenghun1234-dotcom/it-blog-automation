# DEV '본인 인증' 사기, 30초면 간파하고 안전하게 대처하는 법

DEV 커뮤니티에서 'Support Bot'이라는 계정에 태그 당했다면, 절대 클릭하지 마세요. 이건 명백한 사기입니다. 요즘 이런 피싱 수법이 워낙 교묘해서 한순간 방심하면 당하기 쉽지만, 몇 가지만 확인하면 30초 만에 가짜임을 알아챌 수 있습니다. 제가 실무에서 비슷한 사례들을 수없이 봐왔으니, 이 글에서 핵심만 짚어드리겠습니다.

### 이 'Support Bot'이 사기인 이유 (핵심 간파 포인트)

제가 의심스러운 프로필을 딱 한 번 훑어보고 내린 결론입니다. 다음 특징들을 기억하세요.

*   **이름이 수상합니다**: 프로필 이름은 "Suрроrt Воt"으로 보이지만, 자세히 보면 일반적인 라틴 문자가 아닙니다. 특정 문자들이 러시아어 키릴 문자로 교묘하게 대체되어 있죠. (예: `o` 대신 `о`, `p` 대신 `р`). 사실 저도 예전에 피싱 메일을 분석하면서 이런 교묘한 문자열 조작을 자주 접했거든요. 육안으로는 진짜처럼 보여도, 조금만 자세히 보면 확연히 다른 경우가 많습니다.
*   **계정 생성일과 활동 내역이 부자연스럽습니다**: 제가 확인했을 때 이 계정은 11월 4일에 생성되었는데, 작성된 포스팅은 단 하나도 없으면서 댓글만 41개나 달려 있었습니다. 제가 평소에 스팸 계정을 추적할 때도 이런 패턴, 즉 '생성일은 최근인데 댓글 활동만 비정상적으로 많은' 경우를 1순위 의심 대상으로 꼽습니다. 진짜 Support Bot이라면 공식 활동 내역이 분명히 있을 겁니다.
*   **태그 방식이 기계적입니다**: 이 봇은 한 번에 10명씩, 알파벳 순서대로 사람들을 태그합니다. DEV 플랫폼의 실제 운영팀이 이런 식으로 수동으로 알파벳을 훑어가며 태그할 일은 절대 없습니다. 자동화된 스크립트가 분명합니다.
*   **사용자 이름이 이미 바뀌었습니다**: 제가 처음 알림을 받았을 때는 사용자 이름이 'salemsalem123'이었는데, 프로필을 확인하니 이미 'supportbot123'으로 변경되어 있었습니다. 이런 빈번한 계정명 변경은 전형적인 피싱/사기 계정의 특징입니다.

어떤 실제 플랫폼도 낯선 사람의 댓글을 통해 사용자 본인 인증을 요구하지 않으며, 이 과정에서 카드 정보를 요청하는 경우는 절대 없습니다.

### 만약 이미 클릭했다면? 상황별 대처법

실수로 링크를 클릭했거나, 혹은 더 나아가 정보를 입력했다 하더라도 너무 당황하지 마세요. 단계별로 침착하게 대처하면 됩니다.

*   **링크는 클릭했지만, 아무것도 입력하지 않았다면?**
    즉시 해당 탭을 닫고, 브라우저 설정에서 해당 사이트의 데이터를 모두 삭제하세요. 만약을 대비해 다운로드 폴더도 확인해서 의심스러운 파일이 있는지 살펴보는 것이 좋습니다.
*   **앱 권한을 부여했거나 비밀번호를 입력했다면?**
    해당 앱에 부여했던 권한을 즉시 해제하고, 비밀번호를 변경하세요. 특히 다른 서비스와 동일한 비밀번호를 사용하고 있다면, 연쇄 피해를 막기 위해 모든 서비스의 비밀번호를 다르게 변경하는 것을 강력히 권장합니다.
*   **카드 정보를 입력했다면?**
    지체 없이 해당 은행에 전화하여 카드 정지 및 부정 사용 여부를 확인하고 필요한 조치를 취해야 합니다. 시간과의 싸움입니다.

이후에는 해당 계정의 프로필로 이동하여 'Flag' 또는 'Mark as Spam'을 통해 신고해 주세요. 다른 피해자들이 생기지 않도록 하는 중요한 조치입니다.

### 마지막 당부: 10초의 확인으로 피해를 막으세요

어떤 링크든 클릭하기 전에 해당 프로필을 먼저 확인하는 습관을 들이세요. 단 10초만 투자해도 이와 같은 어설픈 사기를 충분히 걸러낼 수 있습니다. 의심스러울 때는 항상 조심하는 것이 가장 안전합니다.
