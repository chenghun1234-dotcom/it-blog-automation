# API 키 없이 바로 쓰는 무료 정부 API 7가지, 실제 서비스에 적용해 본 이야기 (차량 데이터 편)

안녕하세요, 10년 차 IT 실무자이자 테크 블로거 @Elliot Brenya Sarfo입니다.

몇 년 전, 사이드 프로젝트를 위한 무료 API 목록을 공유했는데, 예상치 못하게 큰 호응을 얻었습니다. 덕분에 DEV 커뮤니티에서 제 글 중 가장 많이 읽힌 포스팅이 되었죠. 오늘은 그 경험을 바탕으로, 한 단계 더 나아가 실제 프로덕션 환경에서 검증된 '무료 정부 API'들을 소개하려 합니다. 그것도 API 키나 회원가입, 심지어 신용카드 정보조차 필요 없는 녀석들로 말이죠!

저는 가나에서 사람들이 비즈니스, 가격, 또는 중고차를 거래하기 전에 신뢰도를 확인할 수 있도록 돕는 플랫폼 [TrustCheck](https://trustcheckapp.com)의 공동 창업자입니다. 특히 저희의 무료 중고차 검사 도구는 오늘 소개할 API들을 거의 전적으로 활용하고 있습니다. 모든 예시는 이 글을 작성하면서 제가 직접 실행해 본 요청들이니, 터미널에 바로 복사해서 사용해 보세요.

## 1. NHTSA vPIC: 모든 VIN을 해독해 보세요

**무엇을 얻을 수 있나요?**
17자리 VIN(차량 식별 번호)을 입력하면 차량의 제조사, 모델, 연식, 엔진 크기, 연료 종류, 제조 국가 등 다양한 정보를 얻을 수 있습니다.

```bash
curl "https://vpic.nhtsa.dot.gov/api/vehicles/DecodeVinValues/1HGCM82633A004352?format=json"
```

```json
{
  "Make": "HONDA",
  "Model": "Accord",
  "ModelYear": "2003",
  "DisplacementL": "2.998832712",
  "FuelTypePrimary": "Gasoline",
  "PlantCountry": "UNITED STATES (USA)",
  "ErrorCode": "0"
}
```

**활용 아이디어:**
"광고 내용과 실제 차량이 일치하는가?"를 확인할 수 있습니다. 판매자가 '2015년식'이라고 하는데, VIN을 디코딩해보니 '2009년식'일 수도 있죠. 국내에서도 중고차 시장의 투명성이 중요해지는 시점에서, 이런 정보는 구매자에게 매우 유용합니다. 제가 실무에서 이 부분을 테스트해 봤을 때, VIN 정보만으로 차량의 연식과 제조국을 정확히 파악하면 허위 매물 필터링에 엄청난 도움이 됩니다. 특히 연식 제한이 있는 국가에서는 필수적인 기능이죠.

**주의사항:**
`ErrorCode`를 반드시 확인하세요. `"0"`은 깔끔하게 디코딩되었다는 의미입니다. 일본, 중동, 유럽 등 다른 시장을 위해 제작된 차량은 부분적으로만 디코딩되는 경우가 많으니, 얻은 정보는 모두 보여주되 누락된 정보가 무엇인지 명시하는 것이 좋습니다.

## 2. NHTSA Recalls: 모든 공개 안전 리콜 정보

**무엇을 얻을 수 있나요?**
특정 제조사, 모델, 연식의 차량에 대한 모든 리콜 정보를 확인할 수 있습니다. 어떤 부품에 문제가 있고, 무엇이 잘못되었는지, 그리고 해결책까지 제공합니다.

```bash
curl "https://api.nhtsa.gov/recalls/recallsByVehicle?make=honda&model=accord&modelYear=2003"
```

2003년식 혼다 어코드의 경우 **24개의 리콜**이 검색됩니다. 각 결과에는 `Component`(구성 요소), `Summary`(요약), `Consequence`(결과), `Remedy`(해결책)와 같은 세부 정보와 함께 `parkIt`(운전 금지), `overTheAirUpdate`(OTA 업데이트) 같은 플래그도 포함됩니다.

**주의사항:**
모델명은 NHTSA에서 사용하는 철자법과 정확히 일치해야 합니다. 제가 한번은 6개의 리콜이 있는 GMC 시에라 차량에 대해 "0개의 리콜"이라고 잘못 표시한 적이 있는데, 알고 보니 NHTSA에서는 "SIERRA 1500"으로 등록되어 있었기 때문이었습니다. API #5가 바로 이 문제를 해결해 줄 수 있습니다.

## 3. NHTSA Complaints: 실제 소유주들의 불만사항

**무엇을 얻을 수 있나요?**
차량 소유주들이 직접 신고한 불만사항을 볼 수 있습니다. 충돌, 화재, 부상 및 사망자 수, 관련 부품, 그리고 소유주가 직접 작성한 상세 설명까지 포함됩니다.

```bash
curl "https://api.nhtsa.gov/complaints/complaintsByVehicle?make=honda&model=accord&modelYear=2003"
```

이 요청은 **2,013개의 불만사항**을 반환합니다. 각 항목에는 `crash`(충돌), `fire`(화재), `numberOfInjuries`(부상자 수), `components`(관련 부품), 그리고 소유주의 관점에서 작성된 `summary`(요약)가 포함되어 있습니다.

**활용 아이디어:**
불만사항을 부품별로 집계하여 "이 차량에서 가장 자주 고장 나는 상위 3가지 부품"을 보여줄 수 있습니다. 이는 단순히 스펙 시트를 보는 것보다 구매자에게 훨씬 더 유용한 정보가 될 것입니다.

**주의사항:**
이 엔드포인트는 인기 모델의 경우 응답하는 데 몇 초가 걸릴 수 있습니다. 다른 API 호출과 병렬로 처리하고, 결과를 캐싱하는 것이 좋습니다. 불만 데이터는 시간 단위로 자주 변하지 않기 때문이죠. 제가 이 API를 TrustCheck에 통합하면서 겪었던 가장 큰 문제는 인기 모델의 경우 응답 속도가 생각보다 느리다는 점이었습니다. 다른 정보들과 병렬로 호출하고, 데이터를 공격적으로 캐싱하는 전략이 필수적이었죠. 불만 데이터는 실시간으로 변동하는 정보가 아니니까요.

## 4. NHTSA 5-Star Safety Ratings: 충돌 테스트 사진까지

**무엇을 얻을 수 있나요?**
공식 충돌 테스트 등급과 함께 충돌 테스트 사진 링크(미국 정부 작업물, 공개 도메인)를 제공합니다.

이 API는 두 단계로 작동합니다. 먼저 차량 ID를 찾아야 합니다.

```bash
curl "https://api.nhtsa.gov/SafetyRatings/modelyear/2017/make/toyota/model/corolla"
# → { "VehicleDescription": "2017 Toyota Corolla 4 DR FWD", "VehicleId": 11142 }
```

그다음, 해당 ID로 등급 정보를 가져옵니다.

```bash
curl "https://api.nhtsa.gov/SafetyRatings/VehicleId/11142"
```

```json
{
  "OverallRating": "5",
  "OverallFrontCrashRating": "4",
  "RolloverRating": "4",
  "FrontCrashPicture": "https://static.nhtsa.gov/crashTest/images/2017/v09984P085.JPG"
}
```

**활용 아이디어:**
충돌 테스트 사진을 안전 등급 별점 옆에 배치해 보세요. 사람들은 숫자보다 찌그러진 차량 이미지를 통해 안전성을 훨씬 빠르게 이해합니다.

## 5. NHTSA Products: 모델명 정제 도우미

**무엇을 얻을 수 있나요?**
NHTSA가 특정 제조사와 연식에 대해 사용하는 공식 모델명 목록을 제공합니다. 이 자체로는 특별히 흥미롭지 않지만, API 2번(리콜)과 3번(불만사항)을 안정적으로 사용할 수 있게 해주는 핵심입니다.

```bash
curl "https://api.nhtsa.gov/products/vehicle/models?modelYear=2017&make=gmc&issueType=r"
# → "SAVANA PASSENGER 2500", "CANYON", "ACADIA LIMITED", ...
```

사용자가 "RX 350"이라고 입력해도 NHTSA는 "RX350"이라고 인식합니다. "Sierra"라고 입력해도 리콜은 "SIERRA 1500"으로 분류되어 있죠. 저는 이 목록을 한 번 다운로드(30일 캐싱)하여 양쪽의 공백과 구두점을 제거한 후 매칭합니다. 사용자가 입력한 이름으로 아무것도 찾지 못하면 NHTSA의 공식 철자법으로 다시 시도하는 방식입니다.

**교훈:**
하나의 공급자가 여러 API를 제공하더라도, 그들이 동일한 식별자를 공유한다고 가정해서는 안 됩니다.

## 6. US EPA fueleconomy.gov: 실제 연비 정보

**무엇을 얻을 수 있나요?**
1984년 이후 미국에서 판매된 거의 모든 차량에 대한 공식 도심, 고속도로, 복합 연비 정보를 제공합니다.

이 API는 모델 목록 → 엔진 옵션 → 차량 정보의 단계별 메뉴처럼 작동합니다.

```bash
curl -H "Accept: application/json" \
  "https://www.fueleconomy.gov/ws/rest/vehicle/menu/options?year=2017&make=Toyota&model=Corolla"
# → [{ "text": "Auto (AV-S7), 4 cyl, 1.8 L", "value": "38154" }, ...]

curl -H "Accept: application/json" "https://www.fueleconomy.gov/ws/rest/vehicle/38154"
# → { "city08": "28", "highway08": "35", "comb08": "31", "fuelType": "Regular", "displ": "1.8" }
```

**주의사항:**
`Accept: application/json` 헤더를 포함하지 않으면 XML 형식으로 응답이 옵니다.

**활용 아이디어:**
연비 정보를 리터당 100km ( `235.215 / mpg` )로 변환하고, 여기에 지역 유류 가격을 곱해 보세요. 저희는 도심 연비와 가나의 현재 공식 유류 가격을 사용해 "한 달에 약 GH₵ X 정도의 유류비"를 보여줍니다. 아무도 '갤런당 몇 마일'로 차를 구매하지 않습니다. 사람들이 궁금해하는 건 '한 달에 얼마'죠. 실제로 이 연비 정보를 사용해 월간 예상 연료비를 제공했을 때, 고객들의 반응이 가장 좋았습니다. 단순히 '몇 MPG'보다 '한 달에 얼마'가 훨씬 직관적이고 구매 결정에 큰 영향을 미치더라고요. 단순 계산이지만 사용자에게 실질적인 가치를 줍니다.

## 7. Bank of Ghana: 공식 환율 및 단기국채 금리

**무엇을 얻을 수 있나요?**
중앙은행의 일일 은행 간 환율과 주간 단기국채 금리를 제공합니다.

솔직히 말씀드리면, 이 API는 **공식 문서화된 API가 아닙니다.** 가나 중앙은행(Bank of Ghana)은 이러한 정보를 [bog.gov.gh](https://www.bog.gov.gh/treasury-and-the-markets/historical-interbank-fx-rates/) 웹사이트의 공개 테이블 형태로 게시하고 있으며, 해당 페이지가 데이터를 구조화된 방식으로 로드합니다. 저희는 이 페이지에서 하루에 한 번 데이터를 읽어 캐싱하며, 항상 정해진 페이지에만 요청합니다.

**활용 아이디어:**
"오늘의 달러-세디 환율" 도구를 만들어 공식 환율을 보여줌으로써, 길거리나 상점의 환율이 공식 환율과 얼마나 차이 나는지 사람들이 알 수 있게 할 수 있습니다. 또는 '이번 주 금리로 GH₵1,000을 91일 동안 예치하면 얼마를 벌 수 있는지'를 알려주는 단기국채 계산기도 만들 수 있습니다.

**주의사항:**
정부가 HTML 테이블 형태로만 데이터를 게시하는 경우, '모범적인 시민'이 되어야 합니다. `User-Agent`에 봇을 식별하는 정보를 넣고, 요청 빈도를 낮게 유지하며, 공격적으로 캐싱하여 사이트에 과도한 부담을 주지 마세요. 제가 실무에서 HTML 파싱을 시도할 때는 늘 User-Agent를 명시하고, 하루에 한두 번만 데이터를 갱신하며, 문제가 생기면 즉시 중단할 수 있는 모니터링 시스템을 갖추고 운영합니다. 과도한 요청으로 서버에 부담을 주거나 IP가 차단당하는 일은 절대 피해야 하죠.

## API를 느리거나 차단되지 않게 사용하는 방법

*   **독립적인 호출은 병렬로 실행하세요.** 리콜, 등급, 연비 정보는 서로 의존하지 않습니다. Laravel에서는 `Http::pool()`을 사용해 병렬 처리를 구현합니다.
*   **데이터 변경 주기에 따라 캐싱 기간을 설정하세요.** 모델 목록은 30일, 리콜 및 불만사항은 7일, 환율은 1일 정도로 캐싱합니다.
*   **부분적인 실패는 잠시만 캐싱합니다.** 특정 API가 일시적으로 다운된 경우, 해당 실패 응답은 15분 정도만 캐싱하고 일주일씩 캐싱하지 않습니다.
*   **인기 페이지는 야간에 미리 로드합니다.** 저희는 인기 있는 모델-연식 조합의 데이터를 새벽 1시부터 5시 30분 사이에 소량씩 미리 로드해둡니다.
*   **데이터 출처를 명시하세요.** 페이지에 "출처: NHTSA"와 같이 명시하는 것은 어떤 디자인보다도 사용자에게 신뢰를 줍니다.
