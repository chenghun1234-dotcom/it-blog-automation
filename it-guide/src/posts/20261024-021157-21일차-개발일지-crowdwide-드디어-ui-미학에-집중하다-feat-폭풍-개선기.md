# 21일차 개발일지: Crowdwide, 드디어 UI 미학에 집중하다! (feat. 폭풍 개선기)

새로운 인디 개발자, 소규모 커뮤니티, 그리고 작은 크리에이터들이 더 자유롭게 목소리를 낼 수 있도록 제가 직접 만들고 있는 소셜 미디어 플랫폼, Crowdwide 이야기입니다. 당신의 의견이 어떤 거대 플랫폼에 속해 있느냐로 평가받아서는 안 된다는 신념이 있었죠. 모든 목소리는 동등하게 존중받아야 한다고 믿었거든요.

그리고 오늘이 바로 Crowdwide 개발의 **21번째 날**입니다!!! 드디어! 🔥🔥 Crowdwide는 이제 거의 안정적인 상태에 접어들었어요. 핵심 기능들, 메인 알고리즘, 메일링 시스템, 그리고 추천 시스템인 'Widewave'까지, 드디어 모든 기본 골격이 완성된 거죠!

자, 그렇다면 이제 남은 건 뭐다? 바로 UI 다듬기입니다. 오늘 21일차는 오롯이 Crowdwide의 UI를 '더 아름답게' 만드는 데 집중했어요.

가장 개선이 시급하다고 생각했던 부분은 배경 색상 조합, 테마 적응성, 그리고 사이드바였습니다. (특히 사이드바는 대대적인 수술이 필요했어요!) 이전에는 배경에 그라데이션을 적용했었는데, 사용자들이 스크롤을 많이 할 때마다 배경이 늘어나면서 상단에 이상한 음영이 생기는 문제가 있었죠. 게다가 특정 테마에서는 일부 텍스트 색상이 영 좋지 않아 가독성을 떨어뜨리기도 했습니다. 제가 실무에서 다양한 프로젝트를 진행하며 느낀 건데, 사용자 경험에 직결되는 UI/UX는 사소한 디테일 하나가 전체적인 인상을 좌우하더라고요. 특히 테마나 배경처럼 시각적 기본 요소는 더 그렇죠.

그리고 대망의 사이드바... 정말이지 어떻게 구현해야 할지 머리가 터질 것 같았습니다. 왼쪽에 둘까, 오른쪽에 둘까? 열렸을 때 페이지를 압축해서 밀어낼까? 아니면 페이지 위에 겹쳐지면서 나머지 화면을 살짝 어둡게 만들어 사이드바에 집중하게 할까? 수도 없이 많은 질문들이 제 머릿속을 맴돌았죠. 사이드바 위치나 동작 방식은 정말 개발자들의 영원한 숙제죠. 저도 수많은 프로토타입을 만들어보면서 '이게 최선인가?' 고민했던 기억이 납니다.

수정 또 수정... 고치고 또 고치고... 그렇게 숨 가쁘게 달려와서...
그리고 배포, 배포, 또 배포!

마침내 작업이 완료되었습니다!!!
