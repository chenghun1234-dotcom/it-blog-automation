## AI 아바타, 보안으로 눈을 돌리다

지난 9월 이후 일본에서는 해커들의 무단 접근과 민감 데이터 유출 사건이 폭발적으로 늘었다고 합니다. 일본 인구의 두 배가 넘는 개인 정보가 유출되었다는 소식도 들려오니, 정말 충격적이죠. 이런 보안 상황은 비단 일본만의 문제는 아닐 겁니다. 전 세계적으로 벌어지고 있는 일이며, 개인적으로는 AI 기술 발전의 한 그림자 같다는 생각도 듭니다.

저 역시 지난 1년 넘게 업무와 재미를 위해 AI를 매일같이 사용하고 있는데요, 이 짧은 시간 동안 AI가 얼마나 똑똑해졌는지 직접 체감하고 있습니다. 이러한 흐름 속에서 AI 아바타에도 'AI 아바타 보안(AI Avatar Security)'이라는 보안 지원 기능을 추가해야겠다고 결심했습니다.

물론 제가 보안 전문가는 아니지만, 이 기능을 만들면서 스스로 보안에 대해 배우고 익히는 계기가 되었습니다. 이 경험이 다른 분들께도 도움이 되고, 보안 사고에 대한 경각심을 일깨우는 동기가 되기를 바랍니다.

AI 아바타 보안 기능은 크게 세 가지로 나뉩니다.

*   보안 점검 (Security Check)
*   AI 리뷰 (AI Review)
*   보안 뉴스 (Security News)

### 보안 점검 (Security Check)

보안 점검은 두 가지 유형의 체크를 수행합니다. 바로 라이브러리 취약점 점검과 데이터 유출 점검이죠. 라이브러리 취약점 점검은 `npm audit`을 활용해 알려진 취약점을 확인하고, 어떤 라이브러리에 문제가 있는지 알려줍니다. 데이터 유출 점검은 **Betterleaks** (이전 Gitleaks)를 이용해 노출된 키나 비밀번호를 감지합니다.

솔직히 보안은 개발자에게 마냥 즐거운 분야는 아니죠. 저도 이 기능을 구현하면서 '어떻게 하면 좀 더 경각심을 가지면서도 유쾌하게 접근할 수 있을까?' 고민을 많이 했습니다. 그래서 점검 결과에 따라 아바타 애니메이션을 추가해서, 좀 더 재미있고 동기 부여가 되도록 만들었어요.

#### NG 애니메이션

만약 보안 문제가 발견되면, 바이러스 같은 애니메이션이 재생됩니다. 앱이 실제로 바이러스에 감염되었다는 뜻은 아니고요. 🦠 단순히 보안 점검을 좀 더 재밌게 만들기 위한 시각적 효과입니다.

### AI 리뷰 (AI Review)

AI 아바타에는 무단 접근과 민감 데이터 유출을 방지하기 위한 보안 점검 AI 프롬프트가 추가되었습니다. 필요하다면 이에 대한 테스트 코드 추가 옵션도 제공합니다.

| 카테고리          | AI가 점검하는 내용                 |
| :---------------- | :--------------------------------- |
| 무단 접근         | 로그인 및 인증                     |
| 무단 접근         | 역할 및 권한                       |
| 무단 접근         | 사용자 및 팀 간의 데이터           |
| 무단 접근         | 비공개 파일 및 다운로드            |
| 민감 데이터 유출  | 키 및 비밀번호                     |
| 민감 데이터 유출  | 응답 내의 비공개 데이터            |
| 민감 데이터 유출  | 로그 및 오류 메시지                |
| 민감 데이터 유출  | 공개 파일 및 저장소                |

총 여덟 가지 항목을 한 번에 스캔할 수도 있지만, 각각의 항목을 따로 스캔할 때 훨씬 더 심층적인 분석 결과를 얻을 수 있었습니다.

### 보안 뉴스 (Security News)

최신 보안 뉴스를 확인할 수 있는 기능도 추가했습니다. 두 가지 주요 소스를 활용합니다.

*   **CIS (Center for Internet Security)**: 소프트웨어 취약점에 대한 정보를 제공합니다.
*   **NCSC (National Cyber Security Centre)**: 일반적인 보안 관련 조언을 얻을 수 있습니다.

이 기능을 통해 여러분도 최신 보안 뉴스를 확인하고, 보안 지식을 꾸준히 업데이트하시길 바랍니다.

## AWS 클린업, 미루고 미루던 숙제를 드디어 끝내다

개인적으로 사이버 보안을 점검하고 개선하는 와중에, 미루고 미루던 AWS 계정 정리를 드디어 시작했습니다. 그동안 요금 폭탄을 피하기 위해 서비스를 잠시 중단만 해두고, 삭제는 엄두를 못 냈었죠. 이걸 다 지우려면 너무 복잡하고 시간이 오래 걸릴 것을 직감했거든요.

어떤 서비스는 한 번에 삭제되지 않아 이름을 직접 입력해서 하나씩 지워야 하는 상황도 발생했습니다. 그래서 AI에게 **CloudShell**에서 한 번에 삭제할 수 있는 코드를 짜달라고 부탁했습니다. 처음에는 **CloudWatch** 로그에 보이는 서비스만 지우면 되는 줄 알았는데, 곧 모든 서비스를 커버하지 못한다는 사실을 깨달았죠. 다음으로는 **Resource Explorer**를 사용해 모든 리전에 인덱싱을 활성화하고, 어떤 서비스가 아직 남아있는지 확인했습니다. 그런데 기본 설정이라 삭제할 필요가 없는 서비스까지 뜨는 겁니다. 결국 AI에게 제가 사용했던 서비스만 스캔해서 리스트업 해달라고 요청했고, 마침내 모든 불필요한 서비스를 말끔히 삭제할 수 있었습니다.

이 AWS 클린업 작업은 정말 저의 '귀차니즘'과 '보안 의식'이 싸우는 현장이었죠. 처음엔 간단할 줄 알았는데, 생각보다 복잡해서 제가 AI 모델에게 '이게 다 뭐야?'라며 하소연하면서 코드를 짜달라고 했던 기억이 납니다. 며칠 후, **Cost Explorer**를 확인해보니 서비스를 삭제하는 과정에서 **Config**가 트리거되어 몇 달러가 청구된 것을 발견했습니다. 이렇게까지 힘들고 심지어 돈까지 더 내야 할 줄 알았다면, 그냥 계정 전체를 삭제해 버렸을지도 모르겠네요.

그럼에도 AWS는 워낙 편리하고 다양한 서비스를 제공해서 계속 사용하고 싶습니다. 다만, 이제부터는 정기적으로 클린업을 진행해서 리소스가 너무 쌓이는 일을 방지해야겠다고 다짐했습니다.
