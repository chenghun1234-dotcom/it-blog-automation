# 사진 보안 끝판왕? 13세 개발자가 만든 '온디바이스' AI 편집기 APIC 파헤치기 (Feat. 캔바, 포토피아 비교)

저는 13살에 APIC이라는 서비스를 만들었습니다. 이번 비교 글은 최대한 정직하게 쓰려고 노력했으니, APIC이 부족한 부분도 솔직하게 보여드릴 겁니다.

## 30초 요약: APIC은 무엇인가?

**APIC**은 무료 온라인 사진 편집기이자 배경 제거, 이미지 변환 및 압축 도구입니다. 놀랍게도 이 모든 기능이 **사용자의 브라우저 내에서 완전히 실행**됩니다. 사진은 기기에서 직접 처리되고, AI 모델 또한 로컬에서 구동되죠. 업로드 대기열도, 서버도, 심지어 '크레딧'도 필요 없습니다.

👉 **직접 체험해 보세요:** [APIC-WEB](https://akhouri-anmol-kumar.github.io/APIC-WEB/)

자, 이제 거대 기업들이 긴장하기 전에 미리 밝혀둘게요. 저는 캔바(Canva), 어도비 익스프레스(Adobe Express), 포토피아(Photopea) 또는 리무브닷비지(remove.bg)를 대체하려는 게 아닙니다. 이 서비스들은 각자의 영역에서 훌륭하고, 전문 팀들이 만들고 있죠. 제가 APIC을 만든 이유는 오직 한 가지, 아주 명확한 질문 때문이었습니다.

> **"매일 사용하는 사진 편집 도구들이 내 사진을 전혀 보지 않고도 작동할 수는 없을까?"**

이번 글에서는 다음 내용을 다룹니다:

1.  APIC의 주요 기능
2.  기술적인 작동 방식 (ONNX Runtime Web, 모델 티어, 단일 HTML 파일)
3.  유명 도구 4가지와의 공정한 비교 '배틀'
4.  APIC의 아쉬운 점 (이 부분은 꼭 읽어보세요!)
5.  여러분의 피드백을 받고 싶은 부분

## 작동 방식 (기술적인 부분)

### 1. 단일 파일, 백엔드 없음

APIC은 GitHub Pages에 호스팅된 정적 페이지입니다. 여러분의 이미지를 받는 제 서버는 존재하지 않습니다. 애초에 서버 측 이미지 처리 파이프라인이 없기 때문이죠. 이것이 바로 APIC의 핵심 개인 정보 보호 모델입니다. "절대 받지 않으면 유출될 일도 없다"는 철학이죠.

### 2. ONNX Runtime Web을 통한 브라우저 내 AI 구동

AI 도구들은 [ONNX Runtime Web](https://onnxruntime.ai/)을 통해 모델을 실행합니다. 이때 웹어셈블리(WebAssembly)를 사용하고, 브라우저가 지원하는 경우 웹GPU(WebGPU)도 활용합니다. 모델은 첫 사용 시 브라우저로 다운로드되어 캐시되므로, 첫 AI 실행은 다음 실행보다 느릴 수 있습니다.

배경 제거 기능은 폰부터 게이밍 PC까지 모든 기기에서 원활하게 작동하도록 세 가지 티어를 제공합니다:

| 티어       | 모델 크기 | 적합한 환경         |
| :--------- | :-------- | :------------------ |
| **Light**  | ~5 MB     | 휴대폰 및 느린 연결 |
| **Fast**   | ~44 MB    | 대부분의 노트북     |
| **Maximum** | ~176 MB   | 데스크톱, 최상의 가장자리 디테일 |

객체 제거는 가벼운 모델(~28 MB)과 무거운 "Ultra" 모델(~208 MB)을 제공하며, 업스케일링은 5MB와 64MB 옵션이 있습니다.

간단하게 표현한 작동 방식 (APIC의 정확한 코드는 아니며, 이해를 돕기 위한 예시입니다):

```js
import * as ort from "onnxruntime-web";

// 아래의 모든 코드는 사용자의 기기에서 실행됩니다.
const session = await ort.InferenceSession.create(modelUrl, {
  executionProviders: ["webgpu", "wasm"], // 가장 빠른 사용 가능한 공급자 선택
});

const input = new ort.Tensor("float32", pixels, [1, 3, 1024, 1024]);
const { output } = await session.run({ input });
// ...마스크를 알파값으로 변환하고, 가장자리를 다듬고, <canvas>에 그립니다.
```

제가 10년 전 처음 개발을 시작할 때만 해도 웹에서 이렇게 고성능 AI 모델을 돌리는 건 상상하기 어려웠죠. 서버에서만 가능하다고 생각했는데, ONNX Runtime Web과 WebAssembly의 발전은 정말 격세지감을 느끼게 합니다. 이 부분이 바로 APIC가 '클라이언트 단에서' 강력한 기능을 제공할 수 있는 핵심입니다.

### 3. "그냥 마스크 적용"보다 나은 가장자리 처리

순수한 세그멘테이션 마스크는 배경이 흐릿하게 남는 '후광' 현상을 동반한 컷아웃을 생성할 수 있습니다. APIC은 **Blur-Fusion 전경 추정(Blur-Fusion foreground estimation)** 에 기반한 가장자리 개선 단계를 거칩니다. 이는 대형 모델에서도 사용되는 아이디어로, 머리카락이나 부드러운 가장자리에 이전 배경 색상이 묻어나는 것을 방지하는 데 목적이 있습니다.

### 4. "파일 크기에 맞추는" 압축 기능

단순히 '품질 슬라이더'를 추측해서 조절하는 대신, APIC의 압축 기능은 **품질에 대한 이진 탐색(binary search)** 을 수행합니다. 즉, 목표 크기 미만을 유지하면서도 가능한 한 가장 큰 출력 파일을 생성할 때까지 반복적으로 인코딩하는 방식입니다. 디자인 스튜디오의 "제한에 맞추기" 내보내기 기능도 같은 아이디어를 사용합니다.

### 5. 여기서 말하는 "사생활 보호"의 의미 (그리고 아닌 것)

-   ✅ 여러분의 **이미지**는 로컬에서 처리되며, 서버로 업로드되지 않습니다.
-   ⚠️ **AI 모델 파일**은 공개 호스트(예: Hugging Face 및 jsDelivr)에서 다운로드됩니다. 모델을 다운로드하는 것이 여러분의 사진을 업로드하는 것은 아니지만, 네트워크 트래픽이 발생한다는 점을 명확히 하고 싶습니다.
-   ⚠️ **로그인**하는 경우, Google Sign-In/Firebase는 계정을 위해 여러분의 이름, 이메일, 프로필 사진을 수신합니다. 이 내용은 개인 정보 보호 페이지에 설명되어 있습니다.
-   ⚠️ 사이트에는 운영 비용 충당을 위한 작은 배너 광고가 하나 표시됩니다. (현재까지 수익은 0 달러입니다, 🤣)

이러한 제한 사항들을 여러분이 직접 발견하기보다 제가 먼저 알려드리는 것이 낫다고 생각합니다. 물론 '완벽한 프라이버시'라는 건 없겠지만, APIC처럼 투명하게 한계점을 밝히는 태도는 매우 중요하다고 봅니다. 제가 실무에서 서비스를 기획할 때도 항상 이런 트레이드오프와 투명성을 강조하곤 하죠.

## 4대 거인과의 대결: APIC vs 4 Giants

*아래 사실들은 각 도구의 공식 페이지(하단에 링크됨)에서 확인했으며, 2026년 11월 기준으로 검증되었습니다. 가격 및 제한 사항은 변경될 수 있으니, 결정 전 반드시 확인하시기 바랍니다.*

### 1라운드: 내 사진은 어디로 가는가?

| 도구             | 한 줄 요약                                                                                             |
| :--------------- | :----------------------------------------------------------------------------------------------------- |
| **APIC**         | 기기에서 편집; 이미지는 업로드되지 않음                                                                |
| **Photopea**     | 개인 정보 보호 페이지에 따르면 파일은 "기기를 떠나지 않으며" 자신의 하드웨어로 처리됨                   |
| **Canva**        | 클라우드 에디터; 디자인은 계정에 저장됨                                                                |
| **Adobe Express** | 클라우드 에디터; 작업물은 Adobe 계정에 저장됨 (무료 플랜은 5GB 저장 공간 제공)                         |
| **remove.bg**    | 업로드하는 이미지를 클라우드에서 처리하는 방식                                                         |

**결과:** 로컬 처리 부문에서는 **APIC과 Photopea가 공동 우승**입니다. 클라우드 기반 도구들은 편리함, 협업, 동기화를 위해 개인 정보 보호와 타협하는데, 많은 사람들에게는 합리적인 선택이겠죠.

### 2라운드: 실제로 필요한 기능의 가격

| 도구             | 배경 제거                                                                                                                                                                                                                   |
| :--------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **APIC**         | 무료, 크레딧 없음, 유료 티어 없음                                                                                                                                                                                           |
| **remove.bg**    | 도움말 페이지에 따르면 **0.25 메가픽셀** 이하의 저해상도 이미지에 한해 무료; 고해상도 (최대 50 MP) 및 상업적 사용은 유료 옵션 필요                                                                                     |
| **Canva**        | 타사 플랜 요약에 따르면 배경 제거 및 매직 리사이즈는 **유료 전용** 기능. 현재 정보는 Canva 가격 페이지에서 확인 필요                                                                                                      |
| **Adobe Express** | 무료 플랜은 £0; 프리미엄은 **£9.98/월** (영국 페이지)에 30일 체험판 제공, Adobe FAQ에는 배경 제거가 프리미엄 편집 기능에 포함됨                                                                                         |
| **Photopea**     | 무료 사용 가능, 선택적 유료 프리미엄 플랜 제공                                                                                                                                                                              |

**결과:** APIC이 **이 특정 작업의 가격**에서 승리합니다. 이는 "자금 지원을 받는 클라우드 서비스보다 더 나은 품질"을 의미하는 것은 아니며, 저도 그렇게 주장할 수 없습니다.

### 3라운드: 디자인 및 템플릿 (APIC이 약세인 부분)

어도비 자체 가격 페이지에 따르면 **무료 플랜**에도 **100,000개 이상의 템플릿**과 **4,000개 이상의 폰트**를 제공합니다. APIC의 디자인 스튜디오는 **35개의 오리지널 템플릿**과 **9개의 오픈 라이선스 폰트 패밀리**를 가지고 있습니다.

**결과:** 캔바와 어도비 익스프레스가 압도적으로 승리합니다. 방대한 템플릿 라이브러리, 스톡 사진, 브랜드 키트 또는 팀 협업이 필요하다면 이들을 사용하는 것이 맞습니다. APIC의 디자인 스튜디오는 빠르고, 사적이며, 오프라인에서도 가능한 그래픽 작업을 위한 것입니다.

### 4라운드: 파워 편집 (레이어, PSD, 플러그인)

포토피아는 레이어, PSD 지원, 플러그인 등 포토샵 스타일의 깊이 있는 기능을 갖춘 본격적인 편집기입니다. APIC은 그렇지 않습니다. APIC의 강점은 **특정 작업에 집중된 도구 모음**(컷아웃, 객체 제거, 크기 조절, 변환, 압축, 일괄 처리)으로, 빠르게 열리고 각 탭에서 하나의 작업을 처리합니다.

**결과:** 깊이 있는 편집 기능에서는 포토피아가 승리합니다. APIC은 "10초 안에 이 한 가지 기능이 필요할 때" 승리합니다.

### 5라운드: 대량 및 유틸리티 작업

40장의 이미지를 각각 200KB 미만의 WebP로 변환하거나, 하나의 디자인을 61가지 소셜 미디어 크기로 ZIP 파일로 내보내는 작업은 APIC의 압축, 변환, 일괄 처리, 소셜 미디어 탭이 빛을 발하는 부분입니다. 다른 대형 도구들은 디자인(캔바, 어도비 익스프레스), 완전한 편집(포토피아) 또는 단일 작업(remove.bg)에 집중합니다.

| 빠른 유틸리티 작업 (변환, 압축, 크기 조절, 일괄 처리) | **APIC**                       |
| 팀 협업              | **Canva / Adobe Express**      |

**솔직한 결론:** 이것은 단일 승자가 있는 싸움이 아닙니다. 각기 다른 작업에 최적화된 도구들이죠. APIC은 '일상적인 이미지 작업에 필요한 무료, 사적, 그리고 빠른 도구'라는 빈틈을 채워줍니다.

> 📝 **참고:** remove.bg의 도움말 페이지에 따르면 독립형 웹사이트는 **2026년 12월 1일**부터 더 이상 제공되지 않을 것이라고 합니다. 만약 이 서비스에 의존하고 계셨다면, 온디바이스 옵션을 즐겨찾기에 추가해두는 것이 또 다른 이유가 될 것입니다.

## APIC의 아쉬운 점 (사용하기 전에 꼭 읽어주세요)

*   **내보내기에는 구글 로그인이 필요합니다.** 편집은 자유롭지만, 다운로드는 그렇지 않습니다. 저는 이 기능을 서비스 유지와 실제 사용량 파악을 위해 사용하며, 개인 정보 보호 페이지에 어떤 정보가 저장되는지 설명되어 있습니다.
*   **페이지에 배너 광고가 하나 표시됩니다.**
*   **첫 AI 실행은 느릴 수 있습니다.** 큰 모델(최대 ~176 MB)은 한 번 다운로드됩니다. 휴대폰에서는 Light 티어를 사용해 보세요.
*   **작은 디자인 라이브러리.** 35개의 템플릿과 9개의 폰트 패밀리만 제공하며, 스톡 사진은 없습니다.
*   **실시간 협업 및 클라우드 동기화 기능이 없습니다.**
*   **번역은 아직 검토가 필요합니다.** APIC은 브라우저 언어에 따라 힌디어, 타밀어, 벵골어, 오리야어, 텔루구어를 제안할 수 있지만, 제 번역은 아직 원어민 검토가 필요합니다.
*   **개인(솔로) 프로젝트이며 아직 초기 단계입니다.** 다소 거친 부분이 있을 수 있습니다. 발견하시면 꼭 제보해 주세요.

## 자주 묻는 질문 (FAQ)

**APIC은 정말 무료인가요?**
네. 크레딧이나 유료 티어가 없습니다. 배너 광고와 내보내기를 위한 구글 로그인이 프로젝트 운영에 도움이 됩니다.

**APIC은 내 사진을 업로드하나요?**
아니요. 편집, 변환, 압축, 크기 조절, 배경 제거, 객체 제거는 모두 여러분의 기기에서 실행됩니다. AI 모델 파일만 다운로드됩니다.

**이미지를 업로드하지 않고 배경을 제거할 수 있나요?**
네. APIC의 AI는 ONNX Runtime Web을 사용하여 브라우저에서 실행됩니다.

**오프라인에서도 작동하나요?**
오프라인에서 작동하는 Windows 데스크톱 앱 (APIC for PC)이 있습니다. 웹 버전은 AI 모델을 처음 다운로드할 때 인터넷 연결이 필요합니다.

**왜 로그인하라고 요청하나요?**
결과물을 다운로드하기 위함입니다. 편집 및 미리 보기는 로그인 없이도 가능합니다.

**몇 살부터 사용할 수 있나요?**
13세 이상 (이용 약관 참고). (제가 13살이거든요 🥲)
